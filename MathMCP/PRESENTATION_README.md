# MCP Math Service 展示網頁

## 📋 概述

這是一個專為老師和教育工作者的專業展示網頁，用於介紹 MCP Math Service 項目的特性和功能。網頁採用現代化設計，包含豐富的動畫效果和交互元素。

## 🎨 設計特色

### 視覺設計
- **現代化界面**：採用漸變色彩和卡片式設計
- **響應式佈局**：適配桌面、平板和手機設備
- **專業配色**：學術藍 (#1e3a8a) + 金黃色 (#fbbf24)
- **數學符號背景**：動態浮動的數學符號增強視覺效果

### 動畫效果
- **滾動動畫**：元素隨滾動漸入視野
- **懸停效果**：卡片懸停時的 3D 變換
- **數字計數**：統計數據的動態計數效果
- **符號動畫**：背景數學符號的浮動動畫

## 🚀 快速開始

### 方法一：使用啟動腳本（推薦）
```bash
./start_presentation.sh
```

### 方法二：手動啟動
```bash
# 使用 Python 啟動本地服務器
python3 -m http.server 8080

# 或使用 Python 2
python -m http.server 8080
```

### 方法三：直接開啟
直接雙擊 `presentation.html` 文件，用瀏覽器開啟。

## 📱 訪問方式

啟動後，在瀏覽器中訪問：
- **本地服務器**：http://localhost:8080
- **直接開啟**：file:///path/to/presentation.html
