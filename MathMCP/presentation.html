研究背景與動機

研究問題

在當前的 AI 發展中，大語言模型在數學問題求解方面存在以下挑戰：

  • 計算精度問題：缺乏專業的數學計算引擎支持
  • 工具集成困難：缺乏標準化的工具集成協議
  • 安全性考量：需要防止惡意代碼執行
  • 教育應用需求：需要詳細的解題步驟展示
研究目標：設計並實現一個基於 MCP (Model Context Protocol) 的數學計算服務， 為 AI 模型提供安全、準確、易用的數學問題求解能力。

核心算法實現

def intelligent_tool_selection(expression: str) -> str:
    """智能工具選擇算法"""
    if '=' in expression and any(op in expression for op in ['+', '-', '*', '/']):
        return 'algebra_solve'
    elif any(func in expression for func in ['sin', 'cos', 'tan']):
        return 'trigonometry_calculation'
    elif 'sqrt' in expression or '√' in expression:
        return 'eval_numeric'
    elif any(geo in expression for geo in ['△', '∠', '圓']):
        return 'geometry_calculation'
    else:
        return 'algebra_simplify'

def secure_parse(expression: str) -> bool:
    """安全解析驗證"""
    whitelist = ['x', 'y', 'z', '+', '-', '*', '/', '^', 'sqrt', 'sin', 'cos', 'tan']
    return all(token in whitelist for token in tokenize(expression))
