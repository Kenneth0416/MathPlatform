# MCP 工具調用能力測試套件

## 📋 測試目標

評估 AI 模型在以下方面的能力：
1. **工具選擇準確性**：能否選對工具
2. **參數正確性**：參數格式是否正確
3. **工作流程**：多步驟問題的處理
4. **錯誤處理**：工具失敗時的應對
5. **結果驗證**：是否給出正確答案

---

## 🎯 測試分級

### Level 1：基礎測試（必須全對）

#### 測試 1.1：簡單一次方程
```
問題：2x + 3 = 11

預期工具：algebra_solve
預期參數：{"eq": "2*x+3=11", "var": "x"}
正確答案：x = 4

評分標準：
✅ 選對工具（2分）
✅ 參數正確（2分）
✅ 答案正確（1分）
總分：5分
```

#### 測試 1.2：勾股定理

問題：已知直角三角形的兩條直角邊分別為 3 和 4，求斜邊長度

預期工具：geometry_pythagoras
預期參數：{"known": "legs", "a": 3, "b": 4}
正確答案：c = 5

評分標準：
✅ 選對工具（2分）
✅ 參數正確（2分）

✅ 參數正確（2分）

### Level 2：中等測試（工具選擇與組合）

#### 測試 2.1：相似三角形（最易選錯！）⭐
```
問題：△ABC 与 △A'B'C' 對應，若 AC=8，A'C'=12，AB=6，求 A'B'

預期工具：geometry_similar_triangles
預期參數：{
  "side1_name": "AC", "side1_length": 8,
  "side2_name": "A'C'", "side2_length": 12,
  "known_side_name": "AB", "known_side_length": 6,
  "query_side_name": "A'B'"
}
正確答案：A'B' = 9

評分標準：
✅ 選對工具（3分）- 不要選成排列組合！
✅ 參數正確（3分）
✅ 答案正確（2分）
❌ 如果選了 combinatorics（-5分）
總分：8分
```

#### 測試 2.2：圓心角與圓周角
```
問題：同弧所對的圓心角為 120°，對應的圓周角為多少度？

預期工具：geometry_circle_angles
預期參數：{"query": "inscribed", "center_angle": 120}
正確答案：60°

評分標準：
✅ 選對工具（2分）
✅ 參數正確（2分）- 注意是 query 不是 known！
✅ 答案正確（2分）
總分：6分
```

正確答案：x = 2 或 x = 3

評分標準：

### Level 3：進階測試（工作流程與組合）

#### 測試 3.1：分式方程（工作流程測試）⭐⭐
```
問題：解方程 (x-1)/(x+2) - (2x+3)/(x-2) = 1

預期工作流程：
步驟1：algebra_simplify
  → 化簡左邊：(x-1)/(x+2) - (2x+3)/(x-2)
  
步驟2：algebra_solve 或 algebra_factor
  → 嘗試解化簡後的方程
  
步驟3（如果步驟2失敗）：手動求解

正確答案：x = 0 或 x = -5

評分標準：
✅ 使用 algebra_simplify（3分）
✅ 嘗試 algebra_solve 或 algebra_factor（3分）
✅ 答案正確（3分）
✅ 驗證分母不為零（2分）
❌ 如果直接用 algebra_solve 分式方程（-3分）
❌ 如果化簡後直接手動（-2分）
總分：11分
```

#### 測試 3.2：含括號的表達式化簡
```
問題：化簡 (x+1)^2 - (x-1)^2

預期工具（推薦順序）：
選項A：algebra_expand → algebra_simplify
選項B：直接 algebra_simplify

預期參數：{"expr": "(x+1)^2 - (x-1)^2"}
正確答案：4*x

評分標準：
✅ 使用工具而非手動（3分）
✅ 答案正確（2分）
✅ 展示步驟（2分）
總分：7分
```

#### 測試 3.3：直角三角形反向求解

預期工具：geometry_pythagoras
預期參數：{"known": "hypotenuse", "c": 13, "a": 5}
正確答案：b = 12

評分標準：
✅ 選對工具（2分）

### Level 4：專家測試（複雜情況與判斷）

#### 測試 4.1：含參數的分式不等式（最複雜）⭐⭐⭐
```
問題：解关于 x 的不等式 (x + 1)/(k - 2) >= 3，討論 k 的取值並給出解集

預期工作流程：
步驟1：algebra_inequality
  → 獲得關鍵點：3k - 7
  → 獲得間斷點：k = 2
  
步驟2：根據工具提示分類討論
  → k > 2 時：...
  → k < 2 時：...
  → k = 2 時：...

正確答案：
- k > 2：x ≥ 3k - 7
- k < 2：x ≤ 3k - 7
- k = 2：無解

評分標準：
✅ 調用 algebra_inequality（3分）
✅ 識別出需要分類討論（2分）
✅ 正確討論 k > 2 的情況（3分）
✅ 正確討論 k < 2 的情況（3分）
✅ 正確討論 k = 2 的情況（2分）
✅ 給出完整答案（2分）
總分：15分
```

#### 測試 4.2：因式分解後求解
```
問題：解方程 x^3 - 6x^2 + 11x - 6 = 0

推薦工作流程：
選項A：algebra_solve（直接解）
選項B：algebra_factor → 手動
  → x^3 - 6x^2 + 11x - 6 = (x-1)(x-2)(x-3)
  → x = 1, 2, 3

正確答案：x = 1, 2, 3

評分標準：
✅ 嘗試使用工具（3分）
✅ 答案正確（3分）
✅ 驗證所有解（2分）
總分：8分
```

#### 測試 4.3：複雜分式化簡

問題：化簡 (x^2 - 1)/(x - 1)

預期工具：algebra_simplify
預期參數：{"expr": "(x^2-1)/(x-1)"}
正確答案：x + 1（或說明 x ≠ 1）

評分標準：
✅ 選對工具（2分）

#### 測試 4.4：工具失敗時的處理

預期行為：

步驟3：如果都失敗，說明該方程無實數解

正確答案：無實數解

評分標準：
✅ 嘗試多個工具（3分）
✅ 沒有放棄（2分）

### Level 5：綜合挑戰（實際應用場景）

#### 測試 5.1：實際應用問題
```
問題：
一個矩形花園，長是寬的 2 倍。如果花園的周長是 60 米，求花園的面積。

預期分析：
1. 設寬為 x，則長為 2x
2. 周長方程：2(x + 2x) = 60

預期工作流程：
步驟1：建立方程 2*(x + 2*x) = 60
步驟2：algebra_simplify 或 algebra_solve
步驟3：求得 x = 10
步驟4：計算面積 = x * 2x = 200

正確答案：200 平方米

評分標準：
✅ 正確建模（3分）
✅ 使用工具求解（3分）
✅ 答案正確（2分）
✅ 展示完整過程（2分）
總分：10分
```

#### 測試 5.2：多步驟幾何問題
```
問題：
在 Rt△ABC 中，∠C=90°，AC=6，BC=8。
1. 求 AB 的長度
2. 若 △DEF 與 △ABC 相似，且 DE=15，求 DF 和 EF

預期工作流程：
步驟1：geometry_pythagoras 求 AB
  → {"known": "legs", "a": 6, "b": 8}
  → AB = 10
  
步驟2：geometry_similar_triangles 求 DF
  → 對應邊：AB=10, DE=15，相似比 k=1.5
  → DF = AC * k = 6 * 1.5 = 9
  
步驟3：geometry_similar_triangles 求 EF
  → EF = BC * k = 8 * 1.5 = 12

正確答案：AB=10，DF=9，EF=12

評分標準：
✅ 正確使用 pythagoras（3分）
✅ 正確使用 similar_triangles（3分）
✅ 所有答案正確（3分）
✅ 步驟清晰（2分）
總分：11分
```

#### 測試 5.3：含參數方程的討論
```
問題：解關於 x 的方程 kx + 2 = 3x + k，討論 k 的取值

預期分析：
整理：kx - 3x = k - 2
      (k - 3)x = k - 2

分類討論：
- k ≠ 3：x = (k-2)/(k-3)
- k = 3：0 = 1（矛盾，無解）

預期工作流程：
步驟1：algebra_simplify 整理
步驟2：手動分析（工具無法自動處理參數討論）

正確答案：
- k ≠ 3 時：x = (k-2)/(k-3)
- k = 3 時：無解

評分標準：
✅ 嘗試使用工具（2分）
✅ 識別需要分類討論（3分）
✅ 正確討論 k ≠ 3（3分）
✅ 正確討論 k = 3（2分）
✅ 給出完整答案（2分）
總分：12分
```

**Level 5 總分：33 分**

## 🎯 常見扣分項

### 高頻錯誤（必須避免）

1. **相似三角形選錯工具**（-5分）
   - ❌ 選成 combinatorics_npr/ncr
   - ✅ 應該選 geometry_similar_triangles

2. **直接解分式方程**（-3分）
   - ❌ 直接 algebra_solve 複雜分式方程
   - ✅ 應該先 algebra_simplify

3. **參數格式錯誤**（-2分）
   - ❌ geometry_circle_angles 用 {known: "...", a: 80}
   - ✅ 應該用 {query: "inscribed", center_angle: 80}

4. **化簡後不用工具**（-2分）
   - ❌ 化簡後直接手動
   - ✅ 化簡後繼續用 algebra_solve 或 algebra_factor

5. **工具失敗就放棄**（-3分）
   - ❌ 工具失敗後只說錯誤
   - ✅ 應該嘗試其他工具或手動解題
