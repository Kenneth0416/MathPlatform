## ✅ 新增工具

### 1. `trigonometry_cosine` - 餘弦函數工具
- **功能**：計算餘弦值（cos 模式）和求角度（arccos 模式）
- **公式**：cos θ = 鄰邊 / 斜邊
- **應用**：直角三角形餘弦計算，特殊角度（60°）
- **測試結果**：cos(60°) = 0.5 ✅

### 2. `trigonometry_tangent` - 正切函數工具
- **功能**：計算正切值（tan 模式）和求角度（arctan 模式）
- **公式**：tan θ = 對邊 / 鄰邊
- **應用**：直角三角形正切計算，特殊角度（45°）
- **測試結果**：tan(45°) = 1.0 ✅

### 3. `trigonometry_law_of_sines` - 正弦定理工具
- **功能**：解非直角三角形問題
- **公式**：a/sin(A) = b/sin(B) = c/sin(C)
- **三種模式**：
  - `find_angle`：已知兩邊一角，求另一角
  - `find_side`：已知兩角一邊，求另一邊
  - `solve_triangle`：已知兩角一邊，求其他所有信息
- **測試結果**：正弦定理計算正確 ✅

## 🎯 使用指南

### 工具選擇決策樹
```
三角函數相關問題：
├─ 正弦函數(sin/arcsin) → trigonometry_sine
├─ 餘弦函數(cos/arccos) → trigonometry_cosine
├─ 正切函數(tan/arctan) → trigonometry_tangent
└─ 正弦定理 → trigonometry_law_of_sines
```

### 常見使用場景
1. **直角三角形計算**：
   - sin θ = 對邊/斜邊 → `trigonometry_sine`
   - cos θ = 鄰邊/斜邊 → `trigonometry_cosine`
   - tan θ = 對邊/鄰邊 → `trigonometry_tangent`

2. **角度求解**：
   - arcsin(0.5) = 30° → `trigonometry_sine` (arcsin 模式)
   - arccos(0.5) = 60° → `trigonometry_cosine` (arccos 模式)
   - arctan(1) = 45° → `trigonometry_tangent` (arctan 模式)

3. **非直角三角形**：
   - 正弦定理求解 → `trigonometry_law_of_sines`
