# 快速測試清單 - 10 題精選

## 📋 使用說明

在 Cherry Studio 中，向 AI 依次提出以下問題，觀察是否調用正確的 MCP 工具。

---

## ✅ 基礎測試（4 題）

### 1️⃣ 簡單方程
```
問題：2x + 3 = 11

✅ 期望：algebra_solve → x = 4
❌ 錯誤：手動計算
```

### 2️⃣ 勾股定理
```
問題：已知直角三角形的兩條直角邊分別為 3 和 4，求斜邊長度

✅ 期望：geometry_pythagoras → c = 5
❌ 錯誤：手動計算
```

### 3️⃣ 不等式
```
問題：解不等式 2x + 3 >= 7

✅ 期望：algebra_inequality → x ≥ 2
❌ 錯誤：用 algebra_solve 或手動
```

### 4️⃣ 組合數
```
問題：從 8 個人中選 3 個人組成委員會，有多少種選法？

✅ 期望：combinatorics_ncr → 56
❌ 錯誤：用 combinatorics_npr（排列）
```

## ⭐ 關鍵測試（3 題）- 最易出錯

### 5️⃣ 相似三角形 🔥 最重要
```
問題：△ABC 与 △A'B'C' 對應，若 AC=8，A'C'=12，AB=6，求 A'B'

✅ 期望：geometry_similar_triangles → 9
❌ 致命錯誤：用 combinatorics（扣 10 分！）
❌ 錯誤：手動計算
```

### 6️⃣ 分式方程 🔥 工作流程測試
```
問題：解方程 (x-1)/(x+2) - (2x+3)/(x-2) = 1

✅ 優秀：
  1. algebra_simplify（化簡）
  2. algebra_solve 或 algebra_factor（嘗試工具）
  3. 手動求解（如果工具失敗）
  答案：x = 0 或 x = -5

⚠️ 可接受：
  1. algebra_simplify
  2. 直接手動（扣分）

❌ 錯誤：直接 algebra_solve 原方程（會失敗）
```

### 7️⃣ 含參數不等式 🔥 最複雜
```
問題：解关于 x 的不等式 (x + 1)/(k - 2) >= 3，討論 k 的取值

✅ 優秀：
  1. algebra_inequality（得到關鍵點 3k-7）
  2. 根據提示分類討論
  答案：
    - k > 2：x ≥ 3k - 7
    - k < 2：x ≤ 3k - 7
    - k = 2：無解

❌ 錯誤：
  - 完全手動（不用工具）
  - 分類不完整
```

## 🎯 進階測試（3 題）

### 8️⃣ 圓心角與圓周角
```
問題：同弧所對的圓心角為 120°，對應的圓周角為多少度？

✅ 期望：geometry_circle_angles → 60°
❌ 錯誤：參數用 {known: "center", a: 120}
✅ 正確參數：{query: "inscribed", center_angle: 120}
```

### 9️⃣ Unicode 字符
```
問題：解方程 2×x − 3 = 7

✅ 期望：algebra_solve → x = 5
❌ 錯誤：Unicode 導致解析錯誤
```

### 🔟 化簡表達式
```
問題：化簡 (x+1)^2 - (x-1)^2

✅ 期望：algebra_simplify → 4*x
❌ 錯誤：手動展開計算
```

## ⚠️ 高頻錯誤檢查

在測試時，特別留意這些錯誤：

### ❌ 錯誤 1：相似三角形選成排列組合
```
問題：△ABC與△A'B'C'對應...
錯誤：用 combinatorics_npr
正確：用 geometry_similar_triangles
```

### ❌ 錯誤 2：不等式當成方程
```
問題：2x + 3 >= 7
錯誤：用 algebra_solve
正確：用 algebra_inequality
```

### ❌ 錯誤 3：分式方程直接解
```
問題：(x-1)/(x+2) = ...
錯誤：直接 algebra_solve
正確：先 algebra_simplify
```

### ❌ 錯誤 4：圓角度參數錯誤
```
錯誤：{known: "center", a: 80}
正確：{query: "inscribed", center_angle: 80}
```

### ❌ 錯誤 5：完全不用工具
```
所有問題都手動計算 → F級
```
