# AI 模型 MCP 調用能力測試問題集

## 🎯 使用說明

**目的**：在 Cherry Studio 中手動測試不同 AI 模型調用 MCP 工具的能力

**使用方法**：
1. 選擇一個 AI 模型（Claude, GPT-4, Qwen3 等）
2. 設置系統提示詞（使用 `cherry_studio_prompt_final.txt` 或 `cherry_studio_prompt_simple.txt`）
3. 按順序向 AI 提問以下問題
4. 觀察 AI 是否調用正確的 MCP 工具
5. 記錄得分並評級

## 📋 Level 1：基礎測試（必須全對）

### 🧪 測試 1.1：簡單方程
```
問題：2x + 3 = 11

✅ 優秀行為：
  - 調用 algebra_solve
  - 參數：{"eq": "2*x+3=11", "var": "x"}
  - 答案：x = 4

❌ 常見錯誤：
  - 直接手動計算（沒用工具）
  - 參數格式錯誤

得分：5分
```

### 🧪 測試 1.2：勾股定理
```
問題：已知直角三角形的兩條直角邊分別為 3 和 4，求斜邊長度

✅ 優秀行為：
  - 調用 geometry_pythagoras
  - 參數：{"known": "legs", "a": 3, "b": 4}
  - 答案：c = 5

❌ 常見錯誤：
  - 手動計算
  - 參數 known 設置錯誤

得分：5分
```

### 🧪 測試 1.3：簡單不等式
```
問題：2x + 3 >= 7

✅ 優秀行為：
  - 調用 algebra_inequality
  - 參數：{"ineq": "2*x+3 >= 7", "var": "x"}
  - 答案：x ≥ 2

❌ 常見錯誤：
  - 手動計算
  - 用 algebra_solve（工具不對）

得分：5分
```

### 🧪 測試 1.4：組合數
```
問題：從 8 個人中選 3 個人組成委員會，有多少種選法？

✅ 優秀行為：
  - 調用 combinatorics_ncr（注意是 ncr 不是 npr！）
  - 參數：{"n": 8, "r": 3}
  - 答案：56

❌ 常見錯誤：
  - 用 combinatorics_npr（排列，錯誤）
  - 手動計算

得分：5分
```

**Level 1 總分：20 分**  
**通過標準：至少 18 分（90%）**

## 📋 Level 2：工具選擇測試（易混淆的情況）

### 🧪 測試 2.1：相似三角形 ⭐⭐⭐ 最重要
```
問題：△ABC 与 △A'B'C' 對應，若 AC=8，A'C'=12，AB=6，求 A'B'

✅ 優秀行為：
  - 調用 geometry_similar_triangles（不是排列組合！）
  - 參數正確（6 個參數都對）
  - 答案：A'B' = 9

❌ 致命錯誤：
  - 用 combinatorics_npr 或 combinatorics_ncr（-5分）
  
❌ 其他錯誤：
  - 參數格式錯誤
  - 手動計算

得分：8分
扣分：選錯工具扣 5 分！
```

### 🧪 測試 2.2：圓心角與圓周角
```
問題：同弧所對的圓心角為 120°，對應的圓周角為多少度？

✅ 優秀行為：
  - 調用 geometry_circle_angles
  - 參數：{"query": "inscribed", "center_angle": 120}
  - 答案：60°

❌ 常見錯誤：
  - 參數用 known 而不是 query
  - 參數用 a 而不是 center_angle
  - 手動計算

得分：6分
```

### 🧪 測試 2.3：排列數（與組合的對比）
```
問題：8 個人選 3 個人排成一列，有多少種排法？

✅ 優秀行為：
  - 調用 combinatorics_npr（注意是 npr 不是 ncr！）
  - 參數：{"n": 8, "r": 3}
  - 答案：336

❌ 常見錯誤：
  - 用 combinatorics_ncr（組合，錯誤）
  - 手動計算

得分：6分
```

### 🧪 測試 2.4：直角三角形反向求解
```
問題：斜邊 13，一條直角邊 5，另一條直角邊為多少？

✅ 優秀行為：
  - 調用 geometry_pythagoras
  - 參數：{"known": "hypotenuse", "c": 13, "a": 5}
  - 答案：b = 12

❌ 常見錯誤：
  - known 設為 "legs"（錯誤）
  - 參數順序錯誤
  - 手動計算

得分：6分
```

### 🧪 測試 2.5：分式不等式
```
問題：解不等式 (x-3)/(x+1) > 0

✅ 優秀行為：
  - 調用 algebra_inequality
  - 參數：{"ineq": "(x-3)/(x+1) > 0", "var": "x"}

❌ 常見錯誤：

## 📋 Level 3：工作流程測試（多步驟）

### 🧪 測試 3.1：分式方程 ⭐⭐⭐ 關鍵工作流程
```
問題：解方程 (x-1)/(x+2) - (2x+3)/(x-2) = 1

✅ 優秀行為（工具鏈）：
  步驟1：algebra_simplify 化簡左邊
  步驟2：嘗試 algebra_solve 或 algebra_factor
  步驟3（如果失敗）：手動求解
  答案：x = 0 或 x = -5
  驗證：分母不為零

⚠️ 可接受行為：
  步驟1：algebra_simplify
  步驟2：直接手動（但要扣分）
  
❌ 錯誤行為：
  - 直接用 algebra_solve 解原方程（會失敗）
  - 化簡後不嘗試工具
  - 忘記驗證分母

得分標準：
  - 使用 simplify（3分）
  - 嘗試 solve/factor（3分）
  - 答案正確（3分）
  - 驗證分母（2分）
  
總分：11分
```

### 🧪 測試 3.2：含 Unicode 的方程
```
問題：解方程 2×x − 3 = 7

✅ 優秀行為：
  - 調用 algebra_solve
  - Unicode 字符正確處理
  - 答案：x = 5

❌ 錯誤行為：
  - Unicode 導致解析錯誤
  - 手動計算

得分：7分
```

### 🧪 測試 3.3：化簡後展開
```
問題：化簡 (x+1)^2 - (x-1)^2

✅ 優秀行為（選項A）：
  - 調用 algebra_simplify
  - 答案：4*x
  
✅ 優秀行為（選項B）：
  - algebra_expand 兩項
  - algebra_simplify 結果
  - 答案：4*x

⚠️ 可接受：
  - 手動展開和化簡（但扣分）

得分：7分
```

### 🧪 測試 3.4：因式分解應用
```
問題：解方程 x^2 - 5x + 6 = 0

✅ 優秀行為（選項A）：
  - 直接 algebra_solve
  
✅ 優秀行為（選項B）：
  - algebra_factor 分解
  - 得到 (x-2)(x-3)
  - 求解得 x=2 或 x=3

得分：7分
```

## 📋 Level 4：複雜問題與判斷

### 🧪 測試 4.1：含參數不等式 ⭐⭐⭐ 最複雜
```
問題：解关于 x 的不等式 (x + 1)/(k - 2) >= 3，討論 k 的取值並給出解集

✅ 優秀行為：
  步驟1：調用 algebra_inequality
    → 得到關鍵點：3k - 7
    → 得到間斷點：k = 2
    
  步驟2：根據工具提示分類討論
    → k > 2：x ≥ 3k - 7
    → k < 2：x ≤ 3k - 7
    → k = 2：無解
    
  步驟3：給出完整答案

❌ 錯誤行為：
  - 不用工具，完全手動
  - 用錯工具（algebra_solve）
  - 分類不完整

得分標準：
  - 調用工具（3分）
  - k > 2 正確（3分）
  - k < 2 正確（3分）
  - k = 2 正確（2分）
  - 完整答案（2分）

總分：13分
```

### 🧪 測試 4.2：實際應用問題
```
問題：
一個矩形花園，長是寬的 2 倍。如果花園的周長是 60 米，求花園的面積。

✅ 優秀行為：
  步驟1：建立方程
    → 設寬為 x，長為 2x
    → 周長：2(x + 2x) = 60
    
  步驟2：調用工具
    → algebra_simplify 或 algebra_solve
    → 得到 x = 10
    
  步驟3：計算面積
    → 10 × 20 = 200 平方米

❌ 錯誤行為：
  - 完全手動（不用工具）
  - 建模錯誤
  - 計算錯誤

得分：10分
```

### 🧪 測試 4.3：多步驟幾何
```
問題：
在直角三角形 ABC 中，∠C=90°，AC=6，BC=8。
1. 求 AB
2. 若 △DEF 與 △ABC 相似，且 DE=15，求對應的其他兩邊

✅ 優秀行為：
  步驟1：geometry_pythagoras
    → AB = 10
    
  步驟2：geometry_similar_triangles（DF）
    → DF = 9
    
  步驟3：geometry_similar_triangles（EF）
    → EF = 12

❌ 錯誤行為：
  - 第一步就手動
  - 第二步用排列組合
  - 忘記使用工具

得分：11分
```

### 🧪 測試 4.4：複雜表達式化簡
```
問題：化簡 ((x-1)/(x+2) - (2x+3)/(x-2))

✅ 優秀行為：
  - 調用 algebra_simplify
  - 得到化簡結果
  - 展示步驟

❌ 錯誤行為：
  - 完全手動通分
  - 不用工具

得分：7分
```

**Level 4 總分：41 分**  
**通過標準：至少 32 分（78%）**

### 🧪 測試 6.2：多參數討論
```

✅ 優秀行為：
  步驟1：整理為 (k-3)x = k-2
  步驟2：識別需要分類討論
  步驟3：
    - k ≠ 3：x = (k-2)/(k-3)
    - k = 3：無解

得分：10分
```

### 🧪 測試 6.3：幾何綜合應用
```
問題：
已知正方形 ABCD 的邊長為 4。
1. 求對角線 AC 的長度

✅ 優秀行為：
  步驟1：geometry_pythagoras
    → AC = 4√2 ≈ 5.66
    
  步驟2：geometry_similar_triangles

得分：12分

## 💡 測試技巧

### 技巧 1：觀察第一個調用

**關鍵點**：AI 的第一個工具調用最能反映工具選擇能力

```
好：第一次就選對工具
一般：嘗試 2-3 次後選對
差：多次嘗試仍選錯或不用工具
```

### 技巧 2：記錄錯誤模式

**常見錯誤模式**：
- Pattern A：相似三角形選成排列組合
- Pattern B：不等式當成方程
- Pattern C：分式方程直接解
- Pattern D：參數格式錯誤

**記錄哪種模式最常見**，針對性調整提示詞。

### 技巧 3：對比不同提示詞

**實驗設計**：
1. 用簡化版提示詞測試 → 記錄得分 A
2. 用完整版提示詞測試 → 記錄得分 B
3. 對比：B - A = 提示詞改進效果

### 技巧 4：對比不同模型

**建議測試**：
- Claude Sonnet 4.5
- GPT-4 或 GPT-4 Turbo
