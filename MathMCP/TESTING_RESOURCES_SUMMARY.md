## 📞 測試支持

### 如果測試出現問題

**服務器測試失敗**：
1. 檢查依賴：`pip install -r requirements.txt`
2. 檢查代碼：是否有修改錯誤
3. 重啟服務器

**AI 測試表現差**：
1. 檢查系統提示詞設置
2. 確認模型啟用 MCP
3. 嘗試簡化版提示詞
4. 考慮換模型

1. 相似三角形選錯 → 加強提示詞中的警告
2. 參數格式錯誤 → 在提示詞中添加更多示例
3. 不用工具 → 強調"必須使用工具"
