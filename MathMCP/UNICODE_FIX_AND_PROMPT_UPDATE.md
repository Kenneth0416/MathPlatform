# Unicode 修復與系統提示詞更新

## 📋 問題概述

### 問題 1：Unicode 字符解析失敗 ❌
```
輸入：(x − 1)/(x + 2) − (2x + 3)/(x − 2) = 1
錯誤：invalid character '−' (U+2212)
```

**原因**：用戶輸入的減號是 Unicode 字符 '−' (U+2212)，而不是 ASCII 的 '-'

### 問題 2：AI 遇到錯誤後沒有解題思路 ❌
AI 只說明了錯誤，沒有嘗試手動解題，導致用戶無法得到答案。

---

## ✅ 解決方案

### 1. 服務器端修復：Unicode 字符自動轉換

#### 修改文件
`mcp_math/core/parser.py` - `sanitize_input()` 函數

#### 新增功能
自動將常見的 Unicode 數學符號轉換為 ASCII 符號：

| Unicode 符號 | ASCII 符號 | 說明 |
|-------------|-----------|------|
| − (U+2212) | - | 減號 |
| × (U+00D7) | * | 乘號 |
| ÷ (U+00F7) | / | 除號 |
| √ | sqrt | 平方根 |
| ² | **2 | 平方 |
| ³ | **3 | 立方 |
| （ | ( | 全角括號 |
| ） | ) | 全角括號 |

#### 測試結果
```bash
✅ 輸入：(x − 1)/(x + 2) − (2x + 3)/(x − 2) = 1
   輸出：(x - 1)/(x + 2) - (2x + 3)/(x - 2) = 1

✅ 輸入：2×3÷4
   輸出：2*3/4

✅ 輸入：x²+x³
   輸出：x**2+x**3
```

## 🔧 技術細節

### Unicode 轉換實現

```python
def sanitize_input(expr_str: str) -> str:
    """清理输入表达式，移除危险字符"""
    expr_str = expr_str.strip()
    
    # 替換 Unicode 數學符號為 ASCII 符號
    unicode_replacements = {
        '−': '-',      # Unicode minus (U+2212)
        '×': '*',      # Unicode multiplication sign
        '÷': '/',      # Unicode division sign
        '√': 'sqrt',   # Square root symbol
        '²': '**2',    # Superscript 2
        '³': '**3',    # Superscript 3
        '（': '(',     # Full-width parenthesis
        '）': ')',     # Full-width parenthesis
        '　': ' ',     # Full-width space
    }
    
    for unicode_char, ascii_char in unicode_replacements.items():
        expr_str = expr_str.replace(unicode_char, ascii_char)
    
    return expr_str
```

### 工作流程

```
用戶輸入（含 Unicode）
    ↓
sanitize_input() [自動轉換]
    ↓
parse_expression() [解析]
    ↓
如果成功 → 返回結果
如果失敗 → AI 使用數學知識手動解題
    ↓
用戶得到答案
```
