🚀 最简单的解决方案（3步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: 复制配置文件到 Cherry Studio 配置目录
─────────────────────────────────────────────────────────────────────
mkdir -p ~/.config/cherry-studio
cp /Users/kenneth/Documents/MCP/MathMCP/mcp-servers.json \
   ~/.config/cherry-studio/mcp-servers.json

Step 2: 编辑配置，使用绝对路径
─────────────────────────────────────────────────────────────────────
# 查找 Python 路径
which python3

# 编辑配置文件
nano ~/.config/cherry-studio/mcp-servers.json

# 修改 "command" 为完整路径，例如：
"command": "/Library/Developer/CommandLineTools/usr/bin/python3"

Step 3: 重启 Cherry Studio
─────────────────────────────────────────────────────────────────────
重启后，在 设置 → MCP 服务器 中查看状态
应该显示：✓ math-service 已连接

═══════════════════════════════════════════════════════════════════════

🔧 推荐配置（最稳定）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

文件：~/.config/cherry-studio/mcp-servers.json

{
  "mcpServers": {
    "math-service": {
      "command": "/Library/Developer/CommandLineTools/usr/bin/python3",
      "args": ["-m", "mcp_math.mcp_server"],
      "cwd": "/Users/kenneth/Documents/MCP/MathMCP",
      "env": {
        "PYTHONPATH": "/Users/kenneth/Documents/MCP/MathMCP",
        "PYTHONUNBUFFERED": "1"
      },
      "disabled": false
    }
  }
}

关键点：
  ✓ command 使用绝对路径（which python3 查看）
  ✓ cwd 使用项目的绝对路径
  ✓ PYTHONPATH 设置为项目路径

═══════════════════════════════════════════════════════════════════════

🎯 方案 B: 使用启动脚本（更简单）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

已为您创建：/Users/kenneth/Documents/MCP/MathMCP/run_mcp.sh

Cherry Studio 配置：

{
  "mcpServers": {
    "math-service": {
      "command": "/Users/kenneth/Documents/MCP/MathMCP/run_mcp.sh",
      "disabled": false
    }
  }
}

优点：
  ✓ 更简单，只需一个命令
  ✓ 环境变量已内置
  ✓ 不容易出错

🐛 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题 1: Cherry Studio 显示"未连接"
─────────────────────────────────────────────────────────────────────
原因：Python 路径或项目路径不正确

解决：
  1. 使用 which python3 获取正确路径
  2. 使用绝对路径配置
  3. 检查项目路径是否正确

问题 2: 找不到模块
─────────────────────────────────────────────────────────────────────
原因：PYTHONPATH 未设置

解决：
  在配置中添加：
  "env": {
    "PYTHONPATH": "/Users/kenneth/Documents/MCP/MathMCP"
  }

问题 3: 权限被拒绝
─────────────────────────────────────────────────────────────────────
解决：
  chmod +x /Users/kenneth/Documents/MCP/MathMCP/run_mcp.sh

问题 4: JSON 格式错误
─────────────────────────────────────────────────────────────────────
验证：
  python3 -c "import json; json.load(open('mcp-servers.json'))"

如果没有输出，说明格式正确 ✓
