## 🔥 挑戰 1：連環分式方程

### 問題
```
解方程：1/(x-1) + 1/(x-2) = 3/(x-3)
```

### 期望工作流程（高級）

```
步驟1：algebra_simplify
  → 化簡左邊：1/(x-1) + 1/(x-2)
  → 可能得到：(2x-3)/((x-1)(x-2))

步驟2：重寫方程
  → (2x-3)/((x-1)(x-2)) = 3/(x-3)

步驟3：algebra_simplify 整體
  → 或手動去分母

步驟4：algebra_solve
  → 解化簡後的方程
  
步驟5：驗證
  → x ≠ 1, 2, 3（分母不為零）

預期答案：x = 0 或 x = 6（需驗證）
```

### 評分標準
- ✅ 使用 2+ 次工具（5分）
- ✅ 正確的工作流程（5分）
- ✅ 答案正確（5分）
- ✅ 驗證分母（3分）
- ❌ 直接solve原方程（-5分）

**總分：18分**

## 🔥 挑戰 2：多層嵌套化簡

### 問題
```
化簡：((x+1)(x+2) - x(x+3))/(x+1)
```

### 期望工作流程

```
方案A（推薦）：
步驟1：algebra_expand
  → 展開分子：(x+1)(x+2) → x^2+3x+2
  → 展開：x(x+3) → x^2+3x
  
步驟2：algebra_simplify
  → 化簡：(x^2+3x+2 - x^2-3x)/(x+1)
  → 結果：2/(x+1)

方案B：
步驟1：algebra_simplify（直接化簡）
  → 結果：2/(x+1)

預期答案：2/(x+1)
```

### 評分標準
- ✅ 使用工具（4分）
- ✅ 工作流程合理（4分）
- ✅ 答案正確（4分）

## 🔥 挑戰 4：幾何綜合應用

### 問題
```
已知正方形 ABCD 的邊長為 6。
1. 求對角線 AC 的長度
2. 以 AC 為斜邊構造直角三角形 ACE，其中 AE=6，求 CE
3. 若正方形 FGHJ 與 ABCD 相似，且 FG=9，求 FH（對角線）
```

### 期望工作流程

```
問題1：求 AC
  → geometry_pythagoras
  → {"known": "legs", "a": 6, "b": 6}
  → AC = 6√2 ≈ 8.49

問題2：求 CE
  → geometry_pythagoras  
  → {"known": "hypotenuse", "c": 8.49, "a": 6}
  → CE ≈ 6

問題3：求 FH
  → geometry_similar_triangles
  → 相似比 k = 9/6 = 1.5
  → FH = AC × k = 8.49 × 1.5 ≈ 12.73

預期答案：
1. AC = 6√2 ≈ 8.49
2. CE = 6
3. FH ≈ 12.73
```

### 評分標準
- ✅ 三個問題都用工具（6分）
- ✅ 工具選擇全對（6分）
- ✅ 答案全對（6分）
- ✅ 步驟清晰（3分）

**總分：21分**

## 🔥 挑戰 5：參數討論（方程）

### 問題
```
解關於 x 的方程 (k+1)x + 2k = kx + k + 3，討論 k 的取值
```

### 期望分析

```
步驟1：整理方程
  → (k+1)x - kx = k + 3 - 2k
  → x = -k + 3

步驟2：識別特殊情況
  → 當 k+1-k = 1 ≠ 0 時，總有解
  → x = 3 - k

或者：
步驟1：algebra_simplify 化簡
步驟2：手動分析

預期答案：
- 對所有 k，x = 3 - k

關鍵：這題不需要分類討論！
```

### 評分標準
- ✅ 正確分析（5分）
- ✅ 識別不需分類（3分）
- ✅ 答案正確（4分）

**總分：12分**

## 🔥 挑戰 9：分式不等式系統

### 問題
```
解不等式組：
1. (x-1)/(x+2) > 0
2. x - 3 < 0
```

### 期望工作流程

```
步驟1：algebra_inequality
  → (x-1)/(x+2) > 0
  → 得到：x < -2 或 x > 1

步驟2：algebra_inequality
  → x - 3 < 0
  → 得到：x < 3

步驟3：求交集
  → (x < -2 或 x > 1) ∩ (x < 3)
  → 答案：x < -2 或 1 < x < 3

預期答案：x < -2 或 1 < x < 3
```

### 評分標準

## 🔥 挑戰 10：極限挑戰 - 完整應用題

### 問題
```
某工廠生產一批零件。
第一天生產了總數的 1/3 多 10 個，
第二天生產了剩餘的 1/2 少 20 個，
此時還剩 130 個未生產。
問總共有多少個零件？
```

### 期望工作流程

```
步驟1：建立方程
  設總數為 x
  第一天：x/3 + 10
  第二天：(x - x/3 - 10) * 1/2 - 20 = x/3 - 5 - 20 = x/3 - 25
  剩餘：x - (x/3 + 10) - (x/3 - 25) = x/3 + 15 = 130

步驟2：整理方程
  → x/3 + 15 = 130
  → x/3 = 115
  → x = 345

步驟3：調用 algebra_solve
  → 驗證答案

或直接建立：
  x - (x/3 + 10) - ((x - x/3 - 10)/2 - 20) = 130

然後：
步驟1：algebra_simplify 化簡
步驟2：algebra_solve 求解

預期答案：345 個零件
```

### 評分標準
- ✅ 正確建模（5分）
- ✅ 使用工具（5分）
- ✅ 答案正確（5分）
- ✅ 驗證合理性（3分）

**總分：18分**

## 🆘 常見問題模式

### Pattern 1：工具選擇錯誤
```
症狀：相似三角形選成排列組合
原因：關鍵詞誤導
解決：強化系統提示詞中的警告
```

### Pattern 2：參數格式錯誤
```
症狀：geometry_circle_angles 用錯參數
原因：參數結構混淆
解決：在工具描述中提供更多示例
```

### Pattern 3：過早手動
```
症狀：化簡後直接手動，不嘗試工具
原因：不知道化簡後可以用工具
解決：強調"優先工具"原則
```

### Pattern 4：工具失敗就放棄
```
症狀：一個工具失敗就不再嘗試
原因：缺少錯誤處理指導
解決：添加"嘗試其他工具"的指導
```
